# TP-devops

## Description
Ce projet est réalisé dans le cadre du TP N° 1 du module DevOps.

Il permet d'apprendre à utiliser Git pour gérer les versions d'un projet, créer des branches et collaborer avec GitHub.

## Objectif
Découvrir les commandes essentielles de Git et apprendre à gérer un dépôt local et distant.
